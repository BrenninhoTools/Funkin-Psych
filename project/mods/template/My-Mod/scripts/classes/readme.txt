Polymod scripted classes (.hxc).

A class that extends funkin.play.stages.BaseStage becomes a stage: set "stage" in your chart to the class name (ExampleStage in this template).
You can also extend FlxSprite, FlxSpriteGroup, FlxState, FlxSubState, MusicBeatState and MusicBeatSubstate and create them with Scripted<BaseClass>.scriptInit("ClassName").
