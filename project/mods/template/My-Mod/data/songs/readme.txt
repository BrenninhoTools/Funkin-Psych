Put your song charts here, one folder per song:

data/songs/your-song-name/
---- ./your-song-name-easy.json
---- ./your-song-name.json
---- ./your-song-name-hard.json
---- ./events.json
---- ./preload.json
---- ./script.lua
---- ./script.hx

The audio files go in songs/your-song-name/ (Inst.ogg, Voices.ogg).
