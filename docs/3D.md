# 3D with Foxlite

Funkin' Psych ships [Foxlite](https://github.com/dwdvIl/foxlite), a hardware accelerated 3D renderer for HaxeFlixel, on desktop and mobile builds. Build with `-D NO_FOXLITE` to leave it out.

## Stage JSON

Add a `scene3D` object to a stage. Models are loaded from `models/` paths inside `assets/shared` or a mod folder and can be `.glb`, `.gltf` or `.obj`.

```json
{
	"type": "scene3D",
	"name": "room",
	"position": [0, 0],
	"scroll": [1, 1],
	"size": [1280, 720],
	"camera": { "position": [0, 1, 6], "rotation": [0, 0, 0], "fov": 60, "background": "#00000000" },
	"lights": [
		{ "type": "directional", "position": [3, 5, 4], "color": "#FFFFFF", "energy": 1.2, "shadow": true },
		{ "type": "point", "name": "lamp", "position": [0, 2, 0], "color": "#FFD27F", "range": 8 }
	],
	"models": [
		{ "name": "car", "file": "models/car.glb", "position": [0, 0, 0], "rotation": [0, 45, 0], "scale": [1, 1, 1], "animation": "idle" },
		{ "name": "box", "cube": 1, "texture": "stageback", "position": [2, 0.5, 0], "spin": [0, 1.5, 0] }
	]
}
```

Play an animation from a behavior:

```json
{ "on": "beat", "every": 4, "actions": [{ "action": "play3D", "target": "room", "object": "car", "anim": "jump" }] }
```

## HScript

```haxe
var scene = new Scene3D(FlxG.width, FlxG.height, [0, 1, 6]);
scene.addModel('car', 'models/car.glb');
scene.playAnimation('car', 'idle');
add(scene);
```

`scene.getObject(name)` returns the Foxlite object, so everything in the Foxlite API is available from there.
